# Arogya Drishti

Arogya Drishti is an AI-powered contactless neonatal health monitoring system designed to improve infant care in Neonatal Intensive Care Units (NICUs) and rural healthcare centers.

The system analyzes RGB video captured from a standard camera to estimate vital signs such as heart rate and respiratory rate without attaching physical sensors to the baby. It provides real-time monitoring, intelligent alerts, patient dashboards, analytics, and AI-generated clinical summaries to support healthcare professionals in making faster and informed decisions.

## Key Features

- Contactless vital sign monitoring
- Real-time heart rate and respiration estimation
- AI-powered risk assessment and alerts
- Clinical dashboard for doctors and nurses
- Patient management and analytics
- Role-based secure access
- Privacy-aware monitoring
- Designed for NICUs and rural healthcare environments

## Impact

Arogya Drishti aims to reduce infection risks associated with wearable sensors, improve continuous neonatal monitoring, assist healthcare professionals with early intervention, and make advanced neonatal care more accessible in resource-limited settings.

> **Note:** This project is currently a research prototype developed for innovation and hackathon purposes and is not intended for clinical use.
